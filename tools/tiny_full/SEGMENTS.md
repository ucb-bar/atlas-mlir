# Native Tiny boundary preparation

`capture_boundaries.py` runs the production C orchestration with checksum-bound arithmetic projection replies. It requires the complete128-token prefill plus2greedy-decode capture and its original exact C replay gate. It constructs no device Core and produces no numerical instruction-execution receipt.

The shared C API has begin, layer and finish operations. Begin validates actual tokens and embeds them; layer executes exactly the requested next layer through the unchanged block implementation; finish performs final norm, the full LM head, argmax and committed-state publication. A failed arithmetic operation poisons the continuation. `tiny_full_model_step` composes these same operations, preserving the default full-host flow. `tiny_full_get_live_layout` returns a versioned64-byte ABI descriptor with compiled workspace/hidden offsets and allocation extents; continuation state is32bytes without pointers.

Run the producer with `--capture PATH --capture-sha256 HASH --gate PATH --gate-sha256 HASH --merlin COMPARISONS_DIR --cc PHYSICAL_CC --out FRESH_DIR`. It first checks the full-step path against all465original actual projection predecessors/replies and all132KV arrays,3last-row logits and actual greedy feedback. It repeats the checks through69layer/head phases, clearing dead workspace scratch before each phase. The two ledgers must be identical before preparation passes.

Successful output has70ordered reference boundaries and145fixed regions: four KV banks, two hidden buffers, continuation/control, and all137output-history buffers. Regions have content-addressed payloads; unchanged values share storage. Source snapshots, compiler dependency pins, both original receipts, the compiled native library and every boundary payload are covered by `SHA256SUMS`. `native-gate.json` is a captured-reply C gate compatible with the existing full-host builder, and explicitly has fresh instruction execution false. `receipt.json` has status `PREPARED_REFERENCE_BOUNDARIES_NOT_EXECUTED`; `boundaries.json` has `REFERENCE_BOUNDARIES_ONLY` and `elf_bound=false`.

These semantic snapshots have no physical ELF addresses. A later workload contract must derive and admit the full writable live inventory from a new segment-capable RV64 ELF, bind its actual entry and stop code, and map the compiled layout to that image. The entry must initialize a fresh stack and execute real layers, with global invocation sequence and launch range admitted before a fresh device is constructed. Every link needs actual guest boundary comparisons and exact/drained kernel receipts. Until that runner and its negative control exist, T2 remains incomplete and no segmented numerical qualification is claimed.
