# Activation quantization on Atlas

The application adapter recognizes code and exponent projections from their complete authored semantics. Set the precision policy's `activation_quantizer` to `host` to retain host execution or `device` to select admitted device bodies. No model names or weight transformations participate in selection.

Dense aligned BF16 bodies use ordinary virtual DMA, row and column min/max reduction, allocated i32 arithmetic, runtime-indexed scalar slots, raw dynamic-scale PACK, and counted CFG group, tile, and lane loops. Groups divisible by 1,024 use full 1,024-element tiles. Other aligned groups use a fixed prefix width of `gcd(1024, group_elements)`, with private zero padding. Finite extrema select the ref/nc exponent once per authored group. Exceptional extrema trigger a counted finite-only scalar correction; raw NaN/Inf classification and exponent bit extraction have no BF16 VPU equivalent. Named scalar SSA values pass through allocation and the standard source-derived contracts. PACK clamps its scale shift to [-127,127]; authored signed i32 exponents retain their unclamped values and are stored through an indexed slot.

Static aligned BF16 bodies may process a whole source site when the selected I/O window and the 524,288-element cap admit it. The most expensive prefix geometry costs at most 50 instructions per 32-element tile plus 128 fixed instructions, so `50 * (524288 / 32) + 128 = 819328` stays below the unchanged 1,000,000-instruction limit. Unchanged `npu_model` measured 819,249 instructions at the largest gcd-32 extent, 524,256 elements. Larger requests or smaller I/O windows retain bounded chunks.

Dynamic schedules preserve complete authored reduction groups of at most 4,096 elements. A counted device group loop packs up to eight equal head groups per launch when each group uses full tiles or contains at most 1,024 elements. Short groups may use several fixed-width prefix tiles. A conservative envelope of 64 instructions per lane, 256 per prefix tile and 512 fixed instructions bounds every short group by `64*1024 + 256*32 + 512 = 74240`, below the measured full-group bound. The largest gcd-32 short group, 992 elements, measured 33,495 instructions for ref and 33,521 for nc; eight such groups measured 267,659 and 267,867. Other admitted aligned geometries retain one complete group per launch. All-exceptional 4,096-element groups measured 119,499 instructions for ref and 119,525 for nc; eight groups measured 955,705 and 955,913, respectively, below the unchanged 1M limit. The selected 32-head prefill and decode sites therefore use four launches each; three head sites plus eight static sites use 20 launches per layer. These measurements are functional instruction counts, not cycles or RTL timing.

Invocation C checks pointers, copies bytes, pads private staging, and dispatches the published schedule. The shared slice dispatcher publishes logical codes and exponents only after all device statuses succeed. It performs no activation arithmetic. The host route remains selectable for F32 inputs, ragged BF16 groups, and unsupported group geometries. Whole-body static admission does not imply one launch for every dynamic site or a complete layer.

The unchanged npu_model functional converter `pack_row` agrees with the phase-1 encoder on all 16,711,680 combinations of 65,536 BF16 words and 255 clamped exponents, including ties, signed zeros, subnormals, NaN payloads, infinities, saturation, and carries. This is an exhaustive functional-model comparison, not a fresh RTL simulation. The E8M0 scale byte is the clamped exponent plus 127. Kernel-library ceiling scales and MXU conversion do not replace the authored activation semantics.

The new bodies use virtual scheduling followed by the selected normal physical timing policy, allocation, spilling, delay insertion, and DMA-wait insertion. Publication replays the source and all six standard DMA, MXU, tile, CFG, source-memory, and buffer contracts, plus timing and bounds. The dedicated quantizer descriptor, physical generator, and early-return verification path have been removed. Proof and execution bounds remain at their defaults.

Immutable scalar gathers use the same pipeline: a repeated raw-value tile feeds a counted DMA loop, with padding hidden from logical outputs. Dynamic scalar gathers remain outside this lowering's admitted domain. Multi-image quantizer dispatch uses the existing generic launch-schedule schema; no Merlin core extension is needed.
