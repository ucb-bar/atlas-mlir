# Source-bound complete-K SOTA tile adapter

`tools/atlas_sota_virtual.py` materializes one 32xK by Kx32 output tile from a pinned native operand archive and manifest. By default the archive itself is 32xKx32, retaining the original small-capture payload behavior. Explicit `--row-start` and `--column-start` select an aligned tile from a full captured MxKxN contraction; both coordinates are required and the complete tile must fit. All dimensions are multiples of 32 in [32,4096], the archive has a bounded uncompressed size, and the manifest must declare the complete `[0,K)` reduction. It accepts finite float32 arrays and authenticated raw BF16 views, and requires exact NPZ/manifest SHA-256 pins. It never uses `native_C` as target oracle, trims K, changes MXU unit, inserts synthetic identities or claims native model arithmetic equivalence.

`tools/atlas_sota_arithmetic.py` is the unchanged independent Fraction oracle from the retained Atlas SOTA target recipe, SHA-256 `7976cb9496e31fe9fcfa2bcbbaa2a84c9015c5c471b6c5fef71f5ee94aacc8b0`. It imports neither Torch nor npu_model. The adapter rounds each native float32 operand to BF16, computes the tensor-pow2 scale over the complete captured operand, and applies the retained native VPU PACK equation independently. A scale from a bounded slice is not advertised as the scale of a larger full capture.

The emitted current virtual program loads each raw A/B K32 tile, transposes B once, loads its MXU0 weight, resets the accumulator at the first chunk, then accumulates every subsequent chunk in original K order. It reads the complete BF16 tile, executes the retained splat/multiply rescale recipe, and stores both BF16 halves. State and weight/accumulator resources remain explicit SSA operations outside eclasses. No finite contract is added to the accumulated value; current conservative facts may therefore refuse optimizations, which is a valid result.

Full mode first authenticates the complete captured arrays, their declared M/N/native execution extents, and raw BF16 words for A, B and diagnostic native_C. Declared exported zero rows require the explicit `exported_matrix_zero_rows_only` padding policy, unchanged native mask/position semantics, and actual raw positive zeros in the padded A/native_C rows. The full SmolVLA capture has 177 native rows and 15 exported padding rows; its final 32-row tile contains 17 native and 15 padded rows, rather than 32 new native positions. Padding validation establishes capture consistency, not a target output oracle or a compiler finite-value contract.

Scales and quantization are computed over each entire authenticated A/B before slicing. The full encoder operates on load_source-validated finite float32 arrays and uses exactly the retained high/low-bit BF16 nearest-even rounding equation. It then evaluates the unchanged Fraction scale/PACK oracle for every distinct BF16 code and restores every code to its original position. Taking the maximum over distinct codes equals taking the maximum over the full tensor, and code lookup preserves the scalar recipe exactly. The selected `encoded.npz` contains only the selected A/B tile; the receipt's conversion hashes and scales describe the full operands, while individual DMA input hashes bind the selected chunks. Full receipts add `source_shape`, `selected_tile` row/output-column/K ranges and native/padded row counts, and an explicit scale scope.

The fixture input order is all A K32 tiles followed by all row-major B K32 tiles. Physical output bytes follow the retained oracle's half/row/16-column BF16 layout. Explicit DMA lengths are byte lengths. Selected-memory addresses start at `0x90000000`; the output begins at a disjoint 1024-byte-aligned address after all input tiles, with at least 1024 bytes of guard space. Prefix/suffix and the entire input region are included in full DRAM snapshots. Function ABI attributes are present even though transfers are explicit, because current lowering requires aligned input/output base attributes.

The CLI requires `--input`, `--manifest`, `--npz-sha256`, `--manifest-sha256`, `--name` and a fresh `--out` destination. It emits `source.mlir`, independently encoded operands, immutable initial/expected DRAM images, complete expected output bytes, two invocation fixtures compatible with the generic evaluation executor, and a source-bound materialization receipt. Source hashes are rechecked after oracle generation. Materialization establishes no execution or timing claim.

Qualification must parse and egglog-roundtrip the current virtual source, compile native and roundtripped forms to byte-identical words, then compare every output byte against the independent oracle in fresh model and RTL runs. Full DRAM, VMEM-complement, DMA traffic, completion publication, legal-PC and drained-ECALL checks remain required. The selected native captures are bounded contraction slices, not whole-model quality evidence. Native reference outputs remain diagnostic, and retained historical timing is not reused as fresh qualification.

Portable tests cover source/hash rejection, full raw BF16 authentication, manifest extents, alignment/bounds, padding/tail labels, complete-K/order and unit preservation for K64/K960/K2048, selected-memory ABI rejection, oracle identity, and independence from altered `native_C`. An outlier outside the selected tile proves that scales are computed before slicing. The optimized full encoder is compared with the retained scalar recipe, including rounding ties and signed zeros. A pre-extension snapshot checks the default source/initial/expected/full-output bytes; the same payload check is also applied to all three real small captures in the owned qualification scratch. Adapter identity and destination paths are recorded honestly rather than kept stale. Run `PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s test -p 'test_sota*.py' -v` with the repository tools on PYTHONPATH and a compatible NumPy environment. Synthetic test tensors are explicitly test-only; they are never labeled as ResNet, SmolVLA or TinyLlama captures.
