# Conservative Atlas value facts

`tools/atlas_egglog_facts.py` analyzes immutable `atlas_egglog_ir.Node` dataflow; it does not infer scheduling, state, resource occupancy, engine interchangeability or reduction reassociation. This module needs only Python's standard library. The Node adapter and its directed contract test require the encoder series.

Every BF16 lane is overapproximated by an interval in the exact RTL raw order: `ordered(raw) = raw ^ (0xffff if sign else 0x8000)`. This is a bijection on all 65,536 encodings, matching `VectorParam.compareReturnMin/Max` and `npu_model.configs.rtl_math.minmax`; it distinguishes signed zero and NaN payloads. An absent interval is top, equivalent to the full raw range. Join widens intervals and retains integer/scale information only when both alternatives support it.

Facts expose finite, mathematical sign, exact zero including its possible sign, integer-valued and conversion scale provenance. Finiteness is exactly `low > 0x007f && high < 0xff80`; mathematical nonnegative includes negative zero. `raw_nonnegative` additionally excludes the negative-zero encoding and is the guard required for bit-preserving ReLU elimination. Integer classification uses exact rational BF16 values, never host floating-point comparisons, and transfer preserves noncontiguous integer subsets when both min/max inputs are integer-valued.

Transfers derive exact splat ranges; preserve copies and row extrema; propagate raw-order min/max endpoint bounds; and derive finite ReLU ranges only from finite inputs. Treating top as the full raw interval proves a two-sided finite clamp even when its original source includes NaNs. PACK carries scale metadata without claiming a BF16 interval. UNPACK produces finite BF16 under the inspected `FP8Unpack` equation, including overflow saturation and signed flushed zero; its scale is metadata, not a round-trip equality. General add, subtract, multiply, exponential, reciprocal and opaque loads stay unknown. Typed raw FP8 reset contractions have the conservative closed BF16 interval ±2^25. `analyze_program(program)` also tracks accumulator versions outside the egraph: BF16 loads/readouts copy the source domain, unscaled raw FP8 accumulator expansion is bounded by ±448, and raw FP8 reset readout uses ±2^25. Every accumulate drops the proof, including accumulation from a finite reset. Export these anchor facts through `register_facts(..., program_facts=analyze_program(program), program=program)`.

Caller contracts are explicit premises, bound to the SHA-256 digest of a complete immutable expression tree. Program ingestion additionally requires `Contract.program_sha256` to match the exact current Program source SHA-256; an expression-only contract is permitted only for standalone Node analysis with lexical anchor semantics. `analyze_node` ignores contracts unless `accept_contracts=True`; opted-in contracts intersect derived ranges and contradictory or mismatched contracts raise errors. Contracts do not represent inferred or runtime-checked facts.

Run `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=tools:<encoder-worktree>/tools <egglog-python> -m unittest discover -s test -p test_atlas_egglog_facts.py -v`. The tests exhaust all raw splat classifications and the raw-order bijection, check bounded interval transfers and unknown clamps, and reject unsafe arithmetic and accidental contracts. Fresh model and RTL execution are separate qualification steps; static inspection and these abstract-domain checks establish no timing claim.

The reset bound ports the retained `proposal/exact-conversion-rules` reasoning. E4M3Mul interprets every raw code as integer fields, including normally special encodings; exhaustive 256² products are each below 2^18. Starting at zero, the conservative BF16 rounding recurrence `B[n+1] = (B[n] + 2^18) * 129/128` remains below 2^25 after 32 terms. The IPT tree truncates aligned product magnitudes, has seven headroom bits, and sums at most 32 terms; each aligned integer magnitude is below 2^25 and their sum below 2^30, avoiding signed 32-bit wrap. Its final BF16 rounding remains inside ±2^25. These distinct engine bounds justify finiteness, not engine equivalence or reassociation. Fresh static SSA reanalysis of the pinned corpus preserves all fourteen finite origins and refuses all eight previously unproved/contract-only origins; the scratch origin receipt records exact exports and hashes.

Analysis caches belong to one call. The optional `analyze_node(..., memo=...)` dictionary receives output facts and never supplies cached premises. ProgramFacts carry the exact source SHA-256 and contract-context stamp; seed use requires the matching current `Program`, matching explicit contract admission, and only exports nodes reachable from the requested roots. A local SSA anchor name alone never establishes program identity.
