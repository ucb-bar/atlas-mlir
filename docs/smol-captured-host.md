# RV64 captured-reply host diagnostic

`tools/host_iss/captured_host.py --bundle FULL_SMOL_BUNDLE --model-root PINNED_MODEL --qemu QEMU --out FRESH_OUTPUT --wall-seconds CAP` executes the admitted full Smol ELF under all-stop RV64 QEMU. Use the pinned Model's Python3.14 and explicit one-thread/cache/TMPDIR settings as for the ordinary runner. The default mode is positive; `--mode negative` flips one byte in the final physical padding row and requires the real host FAIL path. This diagnostic requires the generic QEMU NS16550 UART build profile.

This runner never creates or executes a device Core. At every genuine host START it compares the entire staged input/weights/guards/poison image and the exact wrapped IMEM with the authenticated bundle, injects the captured physical projection reply, and resumes the unchanged guest host code. Its CSR counters count protocol accesses only; no cycle measurements or DMA observations are emitted. The positive result is `PASS_RV64_HOST_CAPTURED_REPLIES`, distinct from live numerical-device qualification. Freestanding RV64 host arithmetic, raw result decoding, feedback, all47actual outputs and actual UART/HTIF are checked. Captured replies do not qualify NPU arithmetic or performance.

The QMP helper reads physical memory through bounded `pmemsave` commands only after `query-status` confirms the guest is stopped; RSP owns the CPU breakpoints and writes physical output replies through the identity-mapped guest view. Every dump must have its exact requested length, stale/temporary dumps are removed, and the output path stays in the checked run directory. The helper is independently checked against loader bytes and GDB spot reads before use. A complete live segment run still needs the real Model device and exact next-boundary comparisons.

Source and generator hashes cover static admission and execution; the clean9eModel assembler binding and complete bundle checksums are rechecked. The absolute deadline includes admission and guest execution, interruption triggers QEMU process-group cleanup, and the receipt records source bookends, actual staging/program/reply ledgers, UART hashes, child reap state and memory footprints. The host-only final-state checker is factored from the numerical contract; the ordinary numerical entry still requires its complete ordered exact/drained Model ledger and observed DMA before invoking it.
