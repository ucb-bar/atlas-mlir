# CFG DMA timing proof

`--verify-atlas-timing` proves DMA ownership with `checkAtlasDMACFG` before the existing issue-spacing, reservation, and fixed-latency drain checks. Scheduling preflight keeps `checkAtlasStream` and its existing scope, so this extension does not change scheduling transformations or emitted words.

The abstract domain is a bounded disjunction of correlated register environments and pending launch snapshots. Each register is a singleton RV32 interval or the full RV32 interval. A disjunction retains relations such as `(current, next) = (base, base + stride)` or `(base + stride, base)`, without replacing the buffers by independent sets. This is finite interval reasoning, rather than symbolic affine recurrence solving. Scalar instructions use the existing RV32 transfer functions. Entry registers, loads, CSR results, and link results are unknown unless defined by the modeled scalar instructions; x0 is zero. No reset assumption, tensor value, kit identity, or sampled execution supplies facts.

The CFG worklist starts at block zero. Known scalar branches select their actual successor; unknown branches explore both. The branch reads its predicate before its delay slot executes. Direct jumps, fall-through, halt, and branches to the stream end have explicit edges. Pending launches cross arbitrary CFG edges. A matching-channel wait removes every launch on that channel. Halt, publication, and feasible exits require empty pending ownership. The analysis checks every current footprint against every pending footprint with the selected provider's unchanged `dmaConflict` rule.

Pending state is keyed by static launch instruction and captures register operands at launch. Reusing a register cannot rewrite a captured address. Repeated dynamic launches at one static instruction merge their snapshots, retaining all possible addresses, rather than replacing an older transfer. Different channels and different static launches remain separate obligations.

At 65,536 distinct environments per block, widening replaces the disjunction by one componentwise interval hull and the union of pending launch keys. A disagreeing register becomes the full RV32 interval; it never becomes a new guessed constant. Captured snapshots widen the same way. The built-in provider maps unknown addresses to `anywhere` accesses, so forgetting a value can only lose disjointness proofs. Other provider identities fail closed at this limit or when repeated pending snapshots require widening. This bound affects completeness and cost, never the conditions for acceptance. The public helper accepts a smaller bound for directed unit tests.

For soundness, induct on CFG transitions. The initial abstract state includes every possible restarted-core register state. Scalar transfer includes every concrete result, branch pruning removes only an impossible edge, and each captured pending snapshot includes the operands of every unwaited transfer it represents. Wait kills only its own channel. Joining and widening overapproximate both register values and pending ownership, including a transfer present on only one predecessor. Every processed abstract state checks all represented completion conflicts and exits. Work terminates because each block stores a bounded exact set, then ascends a finite lattice: registers can become unknown only once, and pending keys can only be added. Acceptance occurs only after the worklist empties, including a final check that unsupported widening did not drop the last edge. Therefore every reachable transfer/access pair is covered by a successful provider check.

This proof is relative to the selected timing provider. It does not add DRAM alias rules, change the provider's conservative VMEM alignment and capacity restrictions, prove host accesses, or qualify the provider against hardware. The fixed-latency verifier still checks every emitted block with its existing conservative entry facts and requires fixed-latency work to drain at CFG boundaries. The removed DMA boundary checks duplicated the old one-block DMA scope; their ownership obligation is now discharged across the CFG. The DELAY-before-halt rule remains unchanged. Diagnostics remain fail-fast.

Tests include correlated alternating buffers, cross-block waits, captured-pointer overwrites, known and unknown branches, signed and unsigned predicates, predicate-changing delay slots, dead exit edges, matching-channel ownership, actual and unknown overlaps, pending exits, conservative widening, unsupported provider overflow, fixed-latency drain, and DELAY-before-halt. CLI fixtures minimize the real ResNet50 first-column prefetch loop and inject a one-operand overlap into its paired negative case.
