# Shared exact rewriting and measured selection

The Atlas provider now composes reusable dataflow facts, exact local rule families and guarded PACK conversion alternatives in one actual egglog graph. Merlin owns the generic immutable term/forest representation, bounded fixed-point saturation, joint DAG extraction, pressure-aware shortlist and qualified measured selector. Atlas owns virtual-IR parsing/decoding, real-arithmetic legality, source-bound facts, state/resource materialization, physical verification and model/RTL adapters. This split keeps hardware scheduling out of eclasses while allowing another target to use the same search/selection APIs.

The required Merlin modules are `src/merlin/semantic_compiler/egraph_terms.py` and `rewrite_selection.py`. This prototype uses explicit `PYTHONPATH` selection rather than copying a second generic core into Atlas. Parsing and structural decoding still use only the standard library; optional search requires the pinned egglog package and that Merlin source. The existing Rust `egg` bridge is a different mechanism and is not silently substituted for Python egglog.

## Provider flow

`explore_atlas_egglog.py` reads one supported virtual program and an explicitly supplied observed model timing file. `analyze_program` derives conservative lattice facts from the current program, and `register_facts` exports them into the graph. The exact library supplies copy elimination, double FP8 transpose, raw-order min/max laws and guarded ReLU laws. `pack_rules` adds source-bound alternatives for finite BF16 PACK sites: local raw-order saturation bounds, inverse scale, accumulator push and FP8 pop. Pure conversion recipes enter the egraph; state tokens and real accumulator handles do not.

After extraction, every recipe is restored to its original pure PACK while the remaining dataflow is decoded. `materialize` then reanalyzes the decoded source, checks producer/scale identity, re-proves the selected clamp with the exact library, checks an available accumulator on the selected unit, rematerializes local bounds/scale, and threads the original external state chain. It refuses unknown finiteness, a forged clamp, an exhausted unit or a stale producer. A failed candidate is recorded and native remains available. The real compiler/allocator/timing verifier is mandatory after this structural step; an estimated pressure bound never authorizes allocation.

No contraction is moved between MXU arithmetic engines, no reduction is reassociated and no floating identity is inferred from IEEE behavior. PACK engine alternatives rely on the separately qualified finite conversion equation. No virtual UNPACK identity is invented. `finite_src` metadata is opaque. The reusable analysis API supports explicitly opted-in, source-bound contracts, but this search driver deliberately uses automatically derived facts only.

## Costs and bounded search

`atlas_egglog_cost.py` reads observed per-operation `first_free_age` values and hashes the facts file. It accounts for the known native PACK copy lowering, conversion push/pop/scale operations, VPU/XLU/MXU operation occupancy and buffer/resource liveness. The post-decode DAG estimate charges a producer once and overlaps result demand with its input operands. Matrix-register and accumulator/weight pressure are soft penalties with explicit capacities. Variable DMA latency and common scalar address/control instructions are omitted and reported; this score is a shortlist heuristic, not predicted program cycles.

Pressure uses the allocator's separate banks:32 FP8 registers,15 BF16 pairs when any FP8 result is present or31 pairs for BF16-only programs, and9 scalar value registers with native PACK or17 without. Accumulator and weight slots remain separate two-slot resources per engine. The penalty weights a BF16 pair as two matrix registers and an explicit scalar value by observed scalar-load occupancy. Each resource's peak contributes independently, so the sum is not a single instantaneous physical occupancy. The estimate follows source materialization order; later virtual scheduling can change lifetimes, and actual allocation is still authoritative. Five directed boundary cases compare these capacities and operand/result overlap with real allocation without rescheduling. The initial experiment's combined30-register proxy is retained only in its immutable historical results; it could over-penalize independent banks and understate BF16-only capacity.

The shared extractor jointly extracts the forest of original pure roots. Up to64 bounded extractions perturb exact engine ties using stable source identities, then actual decoded/materialized candidates are rescored. A producer with one distinct PACK recipe keeps its existing seeded preference. If one producer feeds several scale/attribute recipes, their exact PACK attributes extend the preference key so those recipes can choose different engines. Identical immutable PACK terms still share one extracted choice, including when several SSA names denote that term. The report records distinct recipe counts per producer; these are bounded deterministic attempts, not independent enumeration of every named site. Native and both admitted uniform-engine full-clamp controls are retained. Duplicate noncontrol source bytes are removed from the shortlist. Saturation must reach a fixed point within explicit round/row budgets; a truncated search is refused rather than called saturation.

`atlas_hand_reference.py` is an intentionally handwritten evaluation control, not the framework implementation. It applies the same directed local laws with the same raw-bit/sign/interval guards, then enumerates every native/unit0/unit1 assignment at up to6 automatically finite PACK sites. It preserves exact attribute matching, including diagnostic metadata, and preserves ReLU on negative zero. This enumerates a bounded engine product over one directed normal form, not every algebraic shape or schedule.

`compare_atlas_search.py` selects an equal number of cost-ranked distinct sources from each strategy while retaining native and the legacy uniform controls. Identical source SHA-256 values share one measured candidate; `measurement_aliases` preserves independently generated strategy choices so a tie is reported as a tie. Its report contains candidate pools, rejection reasons, operation counts, assignment choices, generation times and the exact scope of the comparison. The full hand pool can also be measured independently; a small shortlist must never be labeled the exhaustive measured optimum.

## Admission and measurement

Generated declarations bind the original program, derived facts, timing facts, implementation source hashes and every selected emitted source SHA-256. They are authenticated provider derivation records, not an independent theorem checker. Compiler verification and the independent output/guard gates remain required. The selection manifest sets `admission_schema` to `atlas.exact-egglog.v1` to require these bindings; legacy arbitrary proof schemas remain available only for legacy manifests.

`select_atlas_candidates.py` remains the subprocess orchestration driver. A strict manifest additionally sets `measurement_metric`, `shared_selection: true` and `tool_pins`. The driver authenticates tool identities before and after each command, checks candidate/source/binary/target/output/oracle/guard receipts, and requires the declared metric and the target's model/RTL tier. Its final `rank_shared` feeds the same qualified receipts and actual emitted binary bytes to Merlin's target-generic `select_measured`; partial candidates cannot win and correctness differences abort. Native is always retained. Compilation refusal is separately reported.

Model and RTL cycles are independent targets. The retained harness measures first issue through drained ecall, with explicit repeated-device invocations and complete output/DRAM/VMEM/completion checks supplied by the adapter. A host functional primitive count from another target must have a separate metric/tier and must not be reported as device timing. The manifest owns the target grid and fixture provenance; the provider does not silently choose a new numerical contract.

## Commands and gates

With `ATLAS_TOOLS`, `MERLIN_SRC`, `EGG_PYTHON`, `TIMING_FACTS`, `SOURCE` and `OUTPUT` set to explicitly selected paths, generate a shortlist with `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$ATLAS_TOOLS:$MERLIN_SRC" "$EGG_PYTHON" "$ATLAS_TOOLS/explore_atlas_egglog.py" "$SOURCE" --timing-facts "$TIMING_FACTS" --output "$OUTPUT"`. Use `compare_atlas_search.py` with the same arguments for the equal-budget hand comparison. Output must be new or empty, including the empty directory created by the measured driver's `extract_argv` adapter protocol.

Run `test_egglog_ir.py`, `test_atlas_egglog_facts.py`, `test_atlas_egglog_rules.py`, `test_atlas_egglog_selection.py` and `test_candidate_selection.py` with both explicit source directories on `PYTHONPATH` and an owned `TMPDIR`. They cover structural roundtrip/extraction, source/contract isolation, signed-zero and unknown-fact refusal, actual exact-rule extraction, all scale recipe boundaries, adjacent state threading, exhausted accumulators, forged clamp/scale choices, complete bounded hand products and authenticated receipt boundaries. Exhaustive arithmetic, allocation stress, independent model/RTL outputs and per-workload measured results belong to the retained external gate manifests; unit tests alone do not qualify timing.

Qualified unary transfer facts use authenticated Atlas raw lookup tables over explicitly bounded source domains. Candidate declarations pin the unary provider module, all three compressed tables, their RTL provenance and the exhaustive qualification manifest alongside the other implementation files. Missing data prevents certificate generation; changing arithmetic data or qualification metadata invalidates existing admission. These facts do not make unrestricted attention softmax finite. See [unary facts](egglog-unary-facts.md).
